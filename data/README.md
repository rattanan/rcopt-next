# Province map coordinates

`thai-province-centers.json` contains approximate province-level reference points, not doctors' or hospitals' locations. Extracted on 2026-10-03 from [Open Admin Data](https://github.com/open-admin-data/thailand-administrative-divisions/blob/main/data/all-province.json), copyright 2026 jakkrapongt, under [CC BY 4.0](https://creativecommons.org/licenses/by/4.0/).

Adaptation: retained Thai province names and converted latitude/longitude strings to numeric pairs. Match on province name because this application's legacy province IDs differ from current administrative codes for some provinces.
